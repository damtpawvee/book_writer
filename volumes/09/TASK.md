# 第九卷　伏魔御厨子（第 177～198 章）

## 进

十月三十一日二十二点二十分前后，他和狗卷在涩谷帐内。他重伤。狗卷左臂还在。五条被封印的喊声刚刚落下。他还不会极之番。

## 这一卷要发生的事

收到十一月一日凌晨他在家入那里醒来。弧线是「被留下的人」的第二段。他在外围，不抢漏瑚、宿傩、东堂、虎杖的战斗。

1. 宿傩的咒力冲上天。他和狗卷把平民藏进道玄坂一带的楼里。
2. 魔虚罗出现。他听轨听出不对，先铺一条大约一公里的轨往外送人。
3. 伏魔御厨子从二十三点零七分到二十三点十四分，半径一百四十米。狗卷用咒言逼他「快走」。他带着挂满人的车先走。极之番「末班车」第一次在这里用：一列旧绿皮车，窗里亮着灯。一车无名平民出了半径一百四十米。回头时那一片已经是平地。没送出去的人照原著死。
4. 狗卷失去左臂，照原著，是为了让他先走。他术式烧断，昏迷。
5. 醒在家入的临时医疗点。醒来才知道：七海死了，钉崎倒下了，五条被封，羂索宣告死灭回游。「车上的人能睡，是因为线上有人醒着」在这一卷出现第二次（第一卷有过第一次）。

编组这一卷可以挂成一列。轨的条数和限速仍是十条、一公里、二百八十公里。不要黑闪。领域还没有。

## 出

十一月一日凌晨，家入的收费站式医疗点。他刚醒，术式烧断，全身像被车撞过。末班车用过第一次。狗卷已经失去左臂。七海的死、钉崎倒下、五条被封、死灭回游的宣告，他都知道了。下一卷从他醒着、铺不出轨写起。

## 不要写

他救下七海或钉崎，他打断伏魔御厨子，他追着宿傩打。屠杀的画面写声音和突然静下来，不写切开的细节。
